- `DAILY_UPLOAD_PLAN.md` — the upload schedule and GitHub workflow.

## Run a File

Install Python 3.10 or later. The examples use the Python standard library.

Windows PowerShell:

```powershell
py .\topics\01_type_casting.py
```

Or run with:

```bash
python topics/01_type_casting.py
```

Some scripts request input. Run each topic file separately.
